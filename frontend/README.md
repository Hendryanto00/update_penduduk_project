# Frontend - React + Vite

## Deskripsi

Proyek frontend ini dibangun menggunakan React dengan Vite sebagai build tool modern yang ringan dan cepat. Aplikasi ini menyediakan antarmuka pengguna untuk mengelola data sinkronisasi dengan fitur upload CSV, login/logout, dan tampilan data dinamis.

## Fitur Utama

- React 18 dengan Functional Components dan Hooks  
- Vite sebagai development server dan bundler dengan Hot Module Replacement (HMR)  
- Tailwind CSS untuk styling cepat dan responsif  
- Autentikasi JWT (login, register, refresh token)  
- Upload CSV dengan validasi kolom dan isi  
- Tabel data dengan pagination dan filter  
- Komunikasi API via Axios  

## Instalasi dan Menjalankan

1. Clone repository:
    - git clone <url-repo-frontend>
    - cd <folder-frontend>

2. Install dependencies:
    - npm install
    # atau
    - yarn install

3. Jalankan development server:
    - npm run dev
    # atau
    - yarn dev

4. Buka browser dan akses:
    - http://localhost:5173
